### 🏗️ Currently building

🧱 **[Concrete Strength Prediction](https://github.com/doubra-daunemigha27/concrete-strength-prediction)**
Can you predict how strong concrete will be just from its recipe? Turns out yes. I built an end to end pipeline on Databricks (raw file → Delta table → Spark SQL → machine learning → predictions back to Delta) where a random forest hit **0.91 R²**, crushing the 0.60 baseline. Then I went hunting for where it fails. 🔍
